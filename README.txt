TADABUR QUR'ANI - PWA

Isi folder:
  index.html            halaman aplikasi
  manifest.webmanifest  data aplikasi (nama, ikon, fullscreen)
  sw.js                 service worker (cache offline)
  icons/                ikon aplikasi

Cara pakai:
1. Unggah SEMUA isi folder ini (bukan zip-nya) ke hosting https,
   misalnya GitHub Pages, Netlify, atau Cloudflare Pages.
2. Buka alamatnya di Chrome (Android) atau Safari (iPhone).
3. Pilih "Instal aplikasi" / "Tambahkan ke layar utama".

Catatan: setelah mengubah index.html, naikkan nomor VERSION di sw.js
(contoh tadabur-v2) agar pembaruan sampai ke HP.
